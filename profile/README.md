## What is Castvane?

Castvane is an independent, open-source project building a self-hosted media streaming and management engine from the ground up in Rust. Its goal is to make it easier to ingest, process, manage, and distribute live media while keeping control of the underlying infrastructure in your hands.

Designed for developers, broadcasters, and self-hosting enthusiasts, Castvane puts performance, reliability, security, and operational simplicity at the center of its engineering approach.

## What we're building

| Area | Direction |
| :--- | :--- |
| Media engine | Flexible stream ingestion, processing, and distribution |
| Stream management | Process lifecycle management, monitoring, and automation |
| Developer experience | API-first architecture and integration-friendly tooling |
| Deployment | Self-hosted infrastructure with straightforward deployment |
| Compatibility | Aiming for API compatibility with datarhei Core |

These are development goals, not a list of currently supported features.

## Our principles

- **Open source:** the core is MIT-licensed.
- **Performance by design:** Rust-based engineering with efficient resource usage in mind.
- **Security by design:** prioritize safe defaults, isolation, and defensive engineering.
- **Own your infrastructure:** keep deployment and operational control in your hands.
- **Built for integration:** favor clear interfaces and flexible workflows.

## Development

Castvane is currently under active development. Explore the [organization's repositories](https://github.com/orgs/Castvane/repositories) for source code and project updates. Feedback, bug reports, and contributions are welcome as the project evolves.

## Independence

Castvane is a standalone project with an independently developed core. It is not affiliated with, endorsed by, or maintained by datarhei. References to datarhei Core describe a technical compatibility goal only.
